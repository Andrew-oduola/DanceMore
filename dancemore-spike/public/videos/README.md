# Move demo clips

Drop the demo clip for each move here as `<move-id>.mp4` (matching the
`demoVideo` path in `public/moves.json`), e.g.:

- `side-step-reach.mp4`
- `arms-up-bounce.mp4`
- `knee-lift-march.mp4`

Keep them short — a few seconds, the move performed once or looping cleanly.
The watch screen loops the clip automatically.

The `.mp4` files currently in this folder are generated test-pattern
placeholders so the player works out of the box — replace them with real
clips using the same filenames. A move without a `demoVideo` entry simply
skips the watch screen.
